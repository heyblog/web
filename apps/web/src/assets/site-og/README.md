# OG fonts

Noto Sans SC Regular and Bold are the unmodified regional OpenType fonts from
[Noto CJK Sans 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/SubsetOTF/SC).
They cover Chinese and Latin text in the server-rendered site share images.

The SIL Open Font License is distributed in `public/licenses/noto-sans-sc.txt`.
The server bundle embeds these fonts; browsers do not download them for page rendering.

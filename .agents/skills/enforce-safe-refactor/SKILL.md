# Enforce Safe Refactor

## 前置条件

- 任务目标是结构优化，不是功能变更
- 单个代码文件的行数上限：后端 400 行；前端 300 行
- 单个函数的行数上限为 50 行

## 行为

1. 先建立行为基线
2. 只做职责拆分、命名统一、重复收敛
3. 用测试与对比验证等价

## 限制

- 禁止改变业务语义
- 禁止改变输入输出契约
- 禁止引入新依赖作为重构前提

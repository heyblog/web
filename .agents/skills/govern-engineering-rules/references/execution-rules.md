# Execution Rules

- 默认在仓库根目录执行命令
- 读取与测试类命令可直接执行
- 高影响非测试命令先向用户确认
- 优先最小变更与最小验证闭环
- 单个代码文件的行数上限：后端 400 行；前端 300 行
- 单个函数的行数上限为 50 行
- 前端项目和 Node 项目在导入对应模块的引用文件时，优先使用模块中 tsconfig.json 中的路径别名配置
- 每次任务结束后，需要将任务相关的所有代码文件使用 git add 命令添加到暂存区，并给出一个包含所有变更文件的 commit，commit message 需要包含本次任务的总结和变更的内容概述
- 在 git add 前，需要使用 build 和 test 命令验证代码的正确性，确保没有语法错误和测试错误
